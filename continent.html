Snake Species by Continent

Africa Asia Europe North America South America Oceania

Important: The Reptile Database regions are geographic distribution regions. A single snake species can occur in more than one region, so the region totals should not be summed to obtain the global number of snake species.

Source: The Reptile Database, Worldwide Diversity of Reptiles. This chart uses the database’s geographic distribution regions and the accepted snake taxon in the Reptile Database advanced search for Serpentes.

Methodology: Counts represent the number of snake species recorded in each geographic distribution region. Because species can be assigned to more than one region, these values are region-level counts rather than unique global totals.
