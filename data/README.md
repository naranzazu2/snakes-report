# Snake search data

Source: [The Reptile Database advanced snake search](https://reptile-database.reptarium.cz/advanced_search?taxon=snake&submit=Search)

The files in this directory were downloaded on 2026-09-19. The advanced search returned 4,249 records from the `snake` taxon.

- `snakes-search.html` is the original webpage downloaded from the source.
- `snakes-search-results.csv` contains the result links in a tabular format.

The CSV columns are:

- `species`: scientific species name
- `authority`: taxonomic author citation
- `url`: link to the record in The Reptile Database

The results are limited to the snake taxon selected by the advanced search. The source database may update its taxonomy over time.
